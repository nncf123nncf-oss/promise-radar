# 返信・約束もれレーダー

LINE・メール・DMの会話を貼ると、「あとで送ります」のような約束や、まだ返していない質問を自動でチェックして一覧にする、`index.html` 1枚の道具です（100日100プロダクト Day058）。

- 仕組み: 言い回しの一覧表を使ったルール判定（端末内）。貼った会話は外部へ送信しません。
- 保存: 抽出した項目だけをこの端末のブラウザ（localStorage、キー `promise-radar:v1`）に保存。会話の全文は保存しません。
- 限界: すべての約束を検出できるわけではありません。遠回しな言い方・辞書にない言い回し・文脈が必要なものは拾えません。
- 検算: `node source/run-tests.js`（架空の会話8本＋サンプル）。これは作者が作った例での確認で、実際の会話での精度の証拠ではありません。
- 期限の解釈: 「今週中・来週中」はその週の金曜（土日に言った「今週中」は翌週の金曜。いずれも「日付は目安」と表示）、「月末」は当月の末日。日付は画面で直せます。
- `?today=YYYY-MM-DD` で「今日」を固定できます（検算・撮影用。使うと画面に表示が出ます）。
